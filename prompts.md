# Prompts — example prompts for each version

These are example prompts that can be used to generate content for each version of the site.

## v1 — Scaffolded site

"Build a homepage for a plumbing business in Melbourne with a hero section, services grid, testimonials, and footer. Use Tailwind CSS for styling."

## v2 — AI blog slop

"Write a comprehensive blog post about low water pressure in homes. Include common causes, DIY fixes, and when to call a plumber. Target keyword: 'plumber for low water pressure'."

## v3 — Voice-injected

"Rewrite the v2 blog post using Marco's voice from references/voice.md. Use stats from references/stats.md for specific numbers. Include anecdotes from references/stories.md where relevant. Use opinions from references/opinions.md where relevant."

## v4 — Landing page

"Build a city+service landing page for 'plumber baldwin park ca' targeting that keyword. Include NAP (name, address, phone), service list, testimonials, and LocalBusiness schema. Use Tailwind CSS."

## v5 — On-page SEO

"Apply the on-page SEO checklist from on-page-seo.md to the v3 blog post. Include FAQ schema, breadcrumb schema, and all meta tags."

## v6 — Technical SEO

"Add sitemap, robots.txt, OG images, favicon, and Organization schema to the v5 site. Ensure all technical SEO checklist items pass."
