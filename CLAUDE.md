# CLAUDE.md — Project instructions

This file is the source of truth for code and content work in this Astro starter. For Spanish, see [`CLAUDE.es.md`](CLAUDE.es.md).

## Project purpose

This is a reusable static Astro starter for local business websites. The original implementation demonstrates an SEO workflow for the fictional Plumbing Co business through `/v1`–`/v6`. The reusable layer includes site configuration, feature flags, content collections, local business SEO components, and CSV-driven input examples.

## Stack and output

- Astro 5
- TypeScript
- Tailwind CSS 4
- `output: 'static'`
- Build output: `dist/`
- CSV input: `examples/template-data/`
- Generated data: `src/generated/template-data.ts`

## Data workflow

1. Edit or replace the CSV files in `examples/template-data/`.
2. Run `npm run validate:data`.
3. Run `npm run import:template`.
4. Review `src/generated/template-data.ts`; do not edit it manually.
5. Run `npm run check` and `npm run build`.

CSV is an input format, not a runtime database. The current importer does not read `.xlsx` files or Google Sheets directly.

## Configuration sources

- `src/config/site.ts` — reusable site and business configuration.
- `src/config/navigation.ts` — navigation items.
- `src/config/features.ts` — feature flags.
- `src/data/business.ts` — compatibility adapter for existing components.
- `src/content.config.ts` — Content Collections schemas.
- `src/generated/template-data.ts` — generated importer output.

Prefer configuration and data imports over hardcoded business values in components. Do not edit generated files manually.

## Content rules

The files in `src/references/` describe the fictional Plumbing Co demo voice and facts. Read them before editing demo content, but do not reuse their claims for another client without replacing them:

- `voice.md`
- `humour.md`
- `stats.md`
- `stories.md`
- `opinions.md`
- `used-keywords.md`

For a new project, replace the demo references with client-specific brand, legal, factual, and editorial data.

## Content locations

- Blog posts: `src/content/blog/*.md`
- Services: `src/content/services/*.md`
- Location input examples: `examples/template-data/locations.csv`
- Long-form page content: Markdown/content collections, not oversized CSV cells.

Frontmatter must match `src/content.config.ts`. Run `npm run check` after changing content schemas or frontmatter.

## Reusable components

- Home: `src/components/home/`
- Blog: `src/components/blog/`
- SEO: `src/components/seo/`
- Site shell: `src/components/site/`

Keep components generic. Business-specific text, numbers, URLs, phone numbers, and review claims belong in configuration or content data.

## SEO and deployment

- Sitemap is generated by `@astrojs/sitemap` from `site` in `astro.config.mjs`.
- `public/robots.txt` must use the real production sitemap URL.
- Canonical URLs, Open Graph URLs, and JSON-LD must use the real site URL.
- Do not publish placeholder domains or demo reviews.
- Validate generated pages and links before deployment.
